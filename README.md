# 讨大白饭

> 一句 `/讨大白饭`，机器人现去 [DeepSeek 开放平台](https://platform.deepseek.com/top_up) 捞一张「充 10 元」的支付宝支付二维码，画成讨饭卡片发到群里。

支付二维码是动态的，15 分钟就作废。所以这个插件不做「存一张图反复发」，而是**每次现取**：

```
/讨大白饭
   └─ 打开一个独立的 Edge/Chrome（自带调试端口，复用已登录的 profile）
      └─ 打开 platform.deepseek.com/top_up
         └─ 选 ¥10 → 选支付宝 → 点「去支付」
            └─ 把弹窗里的二维码 canvas 读出来
               └─ 补白边 → 画成卡片 → 发到群里
```

## 安装

把整个目录丢进 AstrBot 的插件目录：

```
<AstrBot 数据目录>/data/plugins/astrbot_plugin_tao_da_bai_fan/
```

然后在面板里重载插件（或重启 AstrBot）。

依赖：`websockets` 和 `Pillow` 都是 AstrBot 自带的，不用另装。

## 第一次使用：登录一次

插件用一个**独立**的浏览器 profile（`data/plugin_data/astrbot_plugin_tao_da_bai_fan/edge-profile`），
不碰你平时用的浏览器。第一次需要登录：

1. 在群里（或私聊）发 `/讨大白饭 登录`
2. 会弹出一个看得见的 Edge 窗口，停在 DeepSeek 登录页
3. 登录你的开放平台账号，窗口可以留着也可以关掉
4. 再发 `/讨大白饭`，就会收到二维码卡片了

之后插件自己管这个浏览器，随用随开，登录态一直有效。

| `/讨大白饭 登录` | 打开可见的登录窗口（主人） |

## 卡片长什么样

发出去的是一张 760px 宽的图：顶部是 `assets/mascot.png` 那张表情包（自带「我是吃白饭的大肥鱼！」），
下面是二维码，底部是「支付宝扫一扫 · 10 元」和有效期小字。

- 想换形象：直接替换 `assets/mascot.png`（正方形最省事，会裁成圆角贴上去）。
- 删掉这个文件就退回纯文字版式（橙色横条 + 标题 + 副标题）。

## 有人付款就道谢

发出去的那张码对应一笔待支付订单。插件会在后台盯着「账单 → 充值账单」：订单状态从
「已取消 / 待支付」变成「**成功**」时，就回到**当初发码的那个群**说一句谢谢。

```
/讨大白饭 ──> 记一个工单（群 + 时间 + 金额）
                └─ 之后每 20 秒查一次账单（最多盯 20 分钟）
                     └─ 发现「成功」且金额/时间对得上
                        └─ 回群发一条随机道谢文案（{amount} 会被替换成金额）
```

- 匹配规则：状态含「成功」+ 金额一致 + 订单创建时间与发码时间相差 150 秒内；
  一笔订单只道谢一次（订单号写进 `state.json`，重启也不会重复）。
- 多个群几乎同时发码时，一笔订单只会感谢**时间最接近**的那个群。
- 文案一行一条随机挑，可以用 `{amount}` 占位。在插件配置 `thank_texts` 里改。
- 关掉道谢：`enable_thanks = false`。

> 注意：这是**主动消息**（不是回复某条消息）。QQ 官方机器人对主动消息有额度限制，
> 额度用完时 QQ 那边会拒绝，插件会记一条 warning，不影响发码本身。

## 配置要点

| 配置 | 默认 | 说明 |
|---|---|---|
| `amount` | `10` | 充值档位，必须是页面上的固定档：10 / 20 / 50 / 100 / 300 / 500 |
| `card_enabled` | `true` | 画成卡片；关掉就发原始二维码 |
| `cooldown_seconds` | `30` | 同一会话冷却（一次抓码约 10 秒，防止刷屏） |
| `cache_seconds` | `0` | 0 = 每次现捞；大于 0 会复用（同一订单只能付一次，一般别开） |
| `allowed_groups` | 空 | 只在这些群讨饭，逗号分隔；空 = 所有群 |
| `enable_thanks` | `true` | 有人付款就回群道谢 |
| `poll_interval_seconds` | `20` | 查账单的间隔（最小 8 秒） |
| `watch_minutes` | `20` | 一笔订单盯多久（分钟） |
| `thank_texts` | 见配置 | 道谢文案，一行一条，`{amount}` 占位 |
| `admin_openids` | 空 | 额外授权的 openid / QQ，逗号分隔 |
| `headless` | `false` | **别开**。无头模式会被 DeepSeek 风控（页面报「请求异常」） |
| `offscreen` | `true` | 有头但窗口挪到屏幕外，不打扰人 |
| `cdp_port` | `9222` | 本地调试端口，只监听 127.0.0.1 |
| `edge_path` | 空 | 留空自动找 Edge / Chrome |

## 排障

**「捞码翻车了：…登录态失效」**
登录过期了，发 `/讨大白饭 登录` 重新登一次。

**「调试浏览器没有起来（端口没开）」**
多半是 9222 被别的程序占了，改 `cdp_port`；或者杀毒软件拦了浏览器启动。

**「充值页没渲染出金额档位」**
登录态失效，或者 DeepSeek 改了页面结构。先试 `/讨大白饭 刷新`，再试 `/讨大白饭 登录`；
如果还不行，说明页面改版了，需要按新的 DOM 调 `deepseek_qr.py` 里的选择器：

- 金额档位：`input[name="topUpAmount"][value="10"]` 的 `label`
- 支付方式：`input[name="paymentMethod"][value="alipay"]` 的 `label`
- 提交按钮：文本为「去支付」的 `[role=button]`
- 二维码：尺寸 ≥ 100 的 `<canvas>`（`toDataURL`），兜底找 `<img>`

**「等了半天二维码没出来」**
弹窗没弹出来。先 `/讨大白饭 刷新`；持续出现的话检查浏览器窗口能不能正常渲染充值页。

## 说明

- 插件只在你本机驱动浏览器，不把账密或 cookie 发到任何地方。
- 每次 `/讨大白饭` 会在支付宝生成一笔待支付订单（未支付会自然作废），这是正常的。
- 用的 profile 是独立的，删掉 `data/plugin_data/astrbot_plugin_tao_da_bai_fan/edge-profile` 等于「退出登录」。
